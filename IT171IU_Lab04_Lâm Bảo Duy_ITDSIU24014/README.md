### How to Run the Notebook
1. **Google Colab (Recommended):**
   * Upload the `.ipynb` file to your Google Drive and open it with Google Colab.
   * Run the very first cell (**Setup cell**) to install the `ISLP` package and fetch any required datasets.
   * If Colab prompts you to "Restart session", click Accept, and then run the Setup cell one more time.
   * Go to `Runtime` -> `Run all` to execute the entire notebook from top to bottom.
2. **Local Environment (VS Code / JupyterLab):**
   * Ensure you have Python 3.12+ installed.
   * Open the notebook in VS Code or JupyterLab.
   * Select your Python kernel (virtual environment).
   * Run the Setup cell first to ensure `ISLP` and other dependencies (`scikit-learn`, `statsmodels`, `pandas`, `numpy`, `matplotlib`) are installed.
   * Execute all cells sequentially.
